# Daniel's Bakery — Modern Artisan Bakery Landing Page

A responsive, high-contrast landing page built for **Daniel's Bakery**, an artisanal bakery brand based in Lagos, Nigeria. Designed with a dark, warm gold aesthetic to highlight fresh daily bakes, savory pastries, bespoke celebration cakes, and instant ordering channels.

## ✨ Features

- **Sticky Navigation & Fast Jump Links:** Seamless in-page navigation linking to daily bakes, bespoke cake inquiries, and location details.
- **Atmospheric Hero Section:** Mood-lit hero showcase featuring primary order-for-delivery action triggers and custom cake inquiry styling.
- **Featured Menu Grid:** Structured catalog displaying daily artisan breads, flaky beef meat pies, and custom cakes with real pricing in Naira (₦).
- **Custom Event Cakes Consultation:** A 3-step lead-capture process banner designed to walk customers through custom orders (Flavor → Aesthetic → Date confirmation).
- **Storefront & Delivery Logistics:** Transparent operational hours, dispatch zones (Lekki, Ikoyi, VI, Ikeja, Surulere), and physical pickup info.
- **Floating WhatsApp Order Trigger:** High-converting floating contact trigger anchored for quick customer support and order placement.

## 🛠️ Tech Stack

- **Markup:** Semantic HTML5
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Fonts:** [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) & [Dancing Script](https://fonts.google.com/specimen/Dancing+Script)
- **Deployment / Tooling:** PostCSS / Tailwind CLI
